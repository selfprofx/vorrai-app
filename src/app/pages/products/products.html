UTM parameters are invisible tags you attach to your ad destination URLs. They travel with every click — from ad → landing page → SPIN AI — giving the AI full context about who the lead is and what made them click, before the first message is sent.
Standard Parameters
ParameterPurposeExample value
utm_source Where the click came from instagram
utm_medium Marketing channel type cpc
utm_term Keyword or audience interest that matched weight-loss
utm_campaign Maps to your Product. Set this to match your product's UTM Campaign Slug: {{ selectedProduct()!.utm_campaign || 'your-product-slug' }} {{ selectedProduct()!.utm_campaign || 'my-product' }}
utm_content Maps to your Offer. Which specific ad creative or offer the user clicked. Set this to your offer's UTM Content Slug. {{ productOffers()[0]?.utm_content || 'offer-slug' }}
Vendia Custom Parameters
ParameterPurposeExample value

Setting Up in Your Ad Platform
Meta · Facebook · Instagram

In your ad, go to Ad → Destination → Website URL. Paste the full URL with all UTM parameters in the destination field. For multiple ad sets (one per persona), duplicate the ad set and change only utm_persona and utm_content.

Google Ads

Use the Final URL field with the complete URL + UTMs. Alternatively, use the Final URL suffix to append parameters automatically: utm_source=google&utm_medium=cpc&utm_campaign=...

TikTok Ads

In your ad creation flow, set the Landing Page URL to the full URL with UTM parameters appended. TikTok also supports click tracking macros like {{campaign_name}} for dynamic values.

Automatic Capture — Zero Setup Required

Your Vendia landing page automatically reads every UTM parameter from the URL on page load. When a visitor fills in their name and email and submits the form, all UTM values are attached to the submission. No hidden fields, no custom scripts, nothing to configure on the landing page.

How the SPIN AI Uses UTM Data
1
Ad click
User clicks your ad. UTM params are embedded in the destination URL.
2
Landing page
Page silently captures all UTM values. User submits name + email.
3
Email verification
User receives a link with their unique chat token. UTM data travels along inside the system.
4
SPIN conversation opens
Before the first message, the AI already knows: which product they're interested in (utm_campaign), which persona profile they match (utm_persona), and which offer caught their eye (utm_content). The opening is already personalized — no cold start.
Pro tip: Run a separate ad set per persona, each with its own utm_persona value matching one of the personas you created above. When a lead enters the chat, the AI opens with that persona's exact pain points and desires — not a generic script. The result feels like the AI read their mind.
